Seamless MultiLayer (SML) is a novell approach to hybrid calculations described in
40.A.S. Mysovsky, A.I. Bogdanov, Seamless Multi-Layer (SML) - a novel total energy partition scheme for embedded and hybrid calculations, JCTC 2023, vol.19, No. 23, DOI: 10.1021/acs.jctc.3c00666

SEAMLESS2 is the Python3 code which does such type of calculations.
SEAMLESS2 requires:
1) qpp2 (https://github.com/mysovsky/qpp2) installed and working (import qpp should work inside Python)
2) PSI4 quantum chemistry code and Python module

Examples are hoped to be self-explaining. Manual is yet to be written.
